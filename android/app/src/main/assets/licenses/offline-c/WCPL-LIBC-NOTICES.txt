WCPL Library sources
====================

This implementation is mostly derived from `wasi-libc`*, which allows to be licensed
under MIT license (among other options) and algorithms in printed books.
Math routines are ported from Sun's `fdlibm` library.
All attributions in source code are preserved wherever possible.

\* available at https://github.com/WebAssembly/wasi-libc

software is freely granted, provided that this notice
is preserved.

My-CT modification (17/10/2026): bundled stdin and stdout default to
unbuffered I/O for the line-input console. See android/offline-c/prepare.py.
F1 modification: the native compiler also calls a diagnostic callback at fixed
entry/parser/linker/encoder boundaries. No source, path, token or user input is
passed to the callback. Compiler/parser/linker behavior otherwise unchanged.
Original source archives and all other embedded library bytes unchanged.
